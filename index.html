Informazioni Database SQLite Wasm & Schema SQL Mostra dettagli

I dati risiedono in una vera istanza SQLite compilata in WebAssembly. Ad ogni operazione, il database binario viene sincronizzato con la memoria persistente del browser (localStorage/IndexedDB) ed è esportabile integralmente come file .sqlite compatibile con qualsiasi client SQL o come file .json portabile.

CREATE TABLE misurazioni (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  data TEXT NOT NULL, -- 'AAAA-MM-GG'
  slot TEXT NOT NULL, -- 'mattino', 'pranzo', 'cena'
  ora TEXT, -- es. '06:30', '12:30', '19:00'
  max_1 INTEGER NOT NULL, -- Sistolica 1 (mmHg)
  min_1 INTEGER NOT NULL, -- Diastolica 1 (mmHg)
  bat_1 INTEGER NOT NULL, -- Battiti 1 (bpm)
  max_2 INTEGER, -- Sistolica 2 (opzionale)
  min_2 INTEGER, -- Diastolica 2 (opzionale)
  bat_2 INTEGER, -- Battiti 2 (opzionale)
  note TEXT
);
